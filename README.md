# Эмулятор командной строки UNIX (Вариант №27)

Программный комплекс для моделирования работы интерфейса командной строки (CLI) UNIX-систем, функционирующий полностью в оперативной памяти устройства на базе виртуальной файловой системы (VFS) из ZIP-архива.

## Особенности реализации
- **Графический интерфейс:** Реализован на базе библиотеки `tkinter` с полной эмуляцией терминального окна.
- **Изоляция данных:** Все операции управления файлами (`ls`, `cd`, `cp`, `mv`) происходят в оперативной памяти в виде древовидной структуры словарей, исключая прямую работу с физическим жестким диском.
- **Стартовый скрипт:** Поддерживается построчное автоматическое выполнение команд с жестким требованием остановки REPL-цикла при первой же ошибке.
- **Парсинг параметров:** Реализован через стандартный модуль `argparse` с поддержкой подстановки конфигурационных путей по умолчанию.

## Поддерживаемые команды
- `ls` — просмотр содержимого текущей директории виртуальной файловой системы.
- `cd <путь>` — смена текущего каталога (поддерживаются относительные и абсолютные пути).
- `echo <текст>` — вывод строки аргументов на экран терминала.
- `clear` — полная очистка графического текстового поля.
- `cp <откуда> <куда>` — дублирование файлов или директорий по любым путям в памяти.
- `mv <откуда> <куда>` — перемещение и переименование элементов VFS.
- `exit` — корректная остановка главного графического цикла и завершение работы.

## Инструкция по запуску в ОС Windows

Для тестирования различных конфигураций параметров командной строки подготовлены автоматические скрипты запуска реальной ОС в корне проекта:
1. `run_default.bat` — запуск эмулятора со стандартным архивом `vfs.zip` и скриптом `script.txt`.
2. `run_custom.bat` — запуск с кастомным архивом `vfs_custom.zip` и тестовым сценарием.
